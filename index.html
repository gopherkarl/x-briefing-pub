"Karl Pfleger on the reversal test for a common objection to solving aging: 'Imagine a world in which humans don't age. But there are some long-lived dictators who exist.' 'There are all kinds of things you can do about them.' 'Is the best solution to create some kind of virus'"

🔑 Key Takeaway

The reversal test is a weapon against status-quo bias: if a feared outcome were the default, we would not propose its absence as the remedy. Objections to solving aging by pointing at 'long-lived dictators' fail the test because the same worry would not license imposing mortality on everyone. It exposes that the real target of the fear is a solvable political problem, not a reason to forgo a cure.
